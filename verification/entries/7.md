## Task 7: First CLI commands (`fixtures`, `decode`)
Requirements: 16.1, 16.3
### Changes
- `taperescue/cli.py`: argparse CLI with `--version` and two subcommands.
  - `taperescue fixtures [--out DIR]` calls `taperescue.fixtures.starmap.generate(DIR)` (default `fixtures/starmap`, relative to the working directory) and prints the output directory, program size, damage plan source, and WAV SHA-256 values.
  - `taperescue decode CAPTURE.wav [--decoder PATH] [-o OUT.json] [--timeout S]` runs `wavcheck.validate_capture` first, then checks that the decoder exists and is executable, then calls `decode_capture` with a `tempfile.TemporaryDirectory` as `workdir`. The decoder is `--decoder`, else `$TAPERESCUE_DECODER`, else `build/decoder/ScanTape` in the repository. The observations are serialised with `schema.observations_to_doc` as `json.dumps(sort_keys=True, indent=2)` to stdout, or to `OUT.json` with a one-line confirmation on stdout. `--timeout` defaults to the adapter's 60 s; it was added so the timeout path can be tested in under a second. `-o` pointing at the input capture is refused.
  - Every failure prints `error: <reason>` as the last stderr line and returns a non-zero status. argparse usage errors use the same `error:` prefix (custom `ArgumentParser.error`).
- `tests/test_cli.py` (new, 17 tests): the failure paths below, the `python -m taperescue.cli` entry point, `fixtures --out tmp` byte-equal to the checked-in fixtures, and three decode tests that are skipped when `build/decoder/ScanTape` is missing. Fake decoders for the non-zero exit, invalid output, and timeout cases are small shell scripts written to `tmp_path`.

### Exit codes
| Code | Meaning | Source in the design's Error Handling table |
| --- | --- | --- |
| 1 | Other failure (fixture layout error, output cannot be written) | |
| 2 | Usage error (no command, unknown command, `-o` equals the input) | |
| 3 | Capture missing, unreadable, or rejected by wavcheck | wavcheck rows |
| 4 | Export refused (reserved; the design fixes CLI exit 4 for `ExportRefused`) | Exporter, gate refuses |
| 5 | Decoder timeout | Adapter, decoder exceeds 60 s |
| 6 | Decoder missing, cannot start, or non-zero exit | Adapter, non-zero exit |
| 7 | Decoder output invalid | Adapter, schema violation |
| 8 | No BBC 1200-baud blocks | Adapter, no valid header |

### Notes
- When the decoder exits non-zero, the adapter's `log.warning` with the decoder output reaches stderr through Python's last-resort logging handler, before the `error:` line. The CLI does not configure logging.
- Only `taperescue/cli.py`, `tests/test_cli.py`, and this entry were changed. The `fixtures` run rewrote `fixtures/starmap/*` with identical bytes.
