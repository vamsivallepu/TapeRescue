## Task 27.1: Deploy the single container to an Amazon Lightsail container service and verify the public URL

Requirements: 17.1, 17.6, 19.1, 22.2

Run from `/home/vamsik/TapeRescue` on 2026-11-23. Every AWS call used `--profile personal` only; no other profile was read or used.

### Choice of service

The user asked for everything on AWS in one place. Options checked:

| Option | Result |
| --- | --- |
| AWS App Runner | Closed to new customers since 30 April 2026 ([App Runner availability change](https://docs.aws.amazon.com/apprunner/latest/dg/apprunner-availability-change.html)). Not used. |
| Amazon ECS Express Mode (Fargate) | Works, but creates an Application Load Balancer, VPC networking and an ECR repository; estimated well above USD 20 per month for one small task. More parts to maintain. |
| Amazon Lightsail container service | One resource, built-in HTTPS endpoint and image registry, fixed price. Micro power (0.25 vCPU, 1 GB RAM) is USD 10 per month per node, including 500 GB transfer ([Lightsail pricing](https://aws.amazon.com/lightsail/pricing/)). Chosen. |

Scale is fixed at 1: `server/sessions.py` keeps sessions and their temporary files inside the container, so a second node would not find a session created on the first. Micro was chosen over Nano (512 MB) to leave headroom for the decoder subprocess while the server holds an upload.

### Changes

- `scripts/deploy_aws_lightsail.sh` (new): fixed profile `personal`; region, service name, power and image overridable by environment variables. Creates the service if absent (`create-container-service --power micro --scale 1`, tagged `project=taperescue`), waits for it, pushes the image with `push-container-image`, deploys container `app` on port 8000 with a public endpoint health check on `/`, and waits until the deployment is `ACTIVE` with the pushed image. `--build` rebuilds the image first. The header documents the teardown command.
- `README.md`: new step 9 (deploy to AWS, public URL, cost, teardown); the walkthrough intro mentions the public instance; P5 row and the status sentence updated.
- `verification/pending.md`: P5 status and evidence.
- `.kiro/specs/tape-rescue/tasks.md`: new section "AWS deployment" with task 27.1 and wave 36.

### Notes for the user

- The `personal` profile authenticates as the account root user. AWS recommends using an IAM user or role with only the permissions needed instead of root access keys. This task did not change any IAM configuration.
- The service costs USD 10 per month while it exists. Teardown: `aws lightsail delete-container-service --service-name taperescue --profile personal --region us-east-2`.
