## Task 6.8: STARMAP and the fixture generator
Requirements: 4.1, 4.3, 4.6, 4.10, 5.2, 5.5
### Changes
- `fixtures/starmap/STARMAP.bas` (new): original BBC BASIC II program, 106 lines. It sets `MODE 1`, turns the cursor off, sets the palette (logical 1 blue, 2 cyan, 3 white), and seeds the generator with `seed=RND(-42)`. It then draws a 360-point Milky Way band, 240 stars in three brightness classes (the brightest drawn as crosses), a crescent moon made of two filled discs, a meteor, filled hills along the horizon, four constellation figures (Plough, Cassiopeia, Orion, Cygnus) read from `DATA` by `PROCconstellations`, W/N/E compass labels, and a title with a star count, then `END`. It uses only structured code: PROC, FOR/NEXT, IF/THEN/ELSE, and a plain `RESTORE`. It has no line-number references.
- `taperescue/fixtures/starmap.py` (new):
  - `build_program(source)` tokenizes the source and finds the `DEF PROCconstellations` line and its `ENDPROC` with `program_lines()`, which gives the offset and detokenized text of each line. It checks that the main program calls `PROCconstellations` before its `END` line.
  - If the DEF line starts below offset 1536, REM lines are inserted just before it. If the program is under 1793 bytes, REM lines are added at the end. Each REM line is 5 to 255 bytes. The function raises `StarmapLayoutError` in these cases: the procedure is not inside offsets 1536–1791, the length is outside 1793–2048, the block count is not 8, or there are no free line numbers for padding. The checked-in source needs no padding (`padding_lines: []`).
  - `select_damage(payload, crc)` tries the planned flips first (A: 17 bit 2, 143 bit 5; B: 64 bit 0, 201 bit 6), then `fallback_plans()`: 64 plans from `random.Random(0x5747)`, each with four distinct offsets. `check_plan` rejects a plan if the A and B offsets overlap, an offset repeats, a damaged payload still matches the original CRC, or the number of the 16 original/damaged combinations matching the CRC is not exactly 1. Rejected plans and the chosen source are written to `damage.json`.
  - `generate(out_dir, source=None, timing=BBC_TIMING)` writes `clean.wav`, `damaged_a.wav` and `damaged_b.wav` (`block_frames` → `apply_damage` on block 6 → `tape_stream` → `modulate`), `reference_payloads.json` and `damage.json`. JSON is written with `sort_keys=True`, `indent=2`, and no timestamps or paths. The function copies the source into `out_dir` when `out_dir` is not the source directory, and returns `GeneratedFixtures` with the WAV SHA-256 values. Task 7's `taperescue fixtures` command can call it directly.
  - The module imports nothing from `taperescue.decoder_adapter`, does not use `subprocess`, and has no `ScanTape` reference.
- `reference_payloads.json`: filename, load and exec addresses, program length and SHA-256, the PROCconstellations offset range, padding lines, WAV SHA-256 values, and for each block: `block_no`, `block_len`, `flags`, `next_addr`, `header_raw`, `header_crc`, `data_crc`, `hex`, `sha256`.
- `damage.json`: block 6 data CRC, flips for A and B (offset, bit, mask, original and damaged values), the CRCs of the damaged payloads, the plan source with the fallback seed and rejected plans, the candidate check, and the damaged WAV SHA-256 values.
- `tests/test_starmap_generate.py` (new, 11 tests): listing round trip; 8 blocks named STARMAP with flag 0x80 on block 7 only; PROCconstellations inside 1536–1791 and called before END; padding of a shortened source; rejection of an over-long source; planned plan accepted and overlapping plan rejected; fixed fallback list; consistency of the JSON records and WAV headers; determinism across two runs; checked-in fixtures equal to fresh generator output; generator import check.

### Notes
- The first draft of STARMAP was 2299 bytes, with the DEF line at offset 1730. Header and per-procedure comment lines were removed, and the two comment lines describing the DATA format were replaced by one line, `2900 REM Constellations`, in front of the procedure. The final source lays out without padding. The padding code path is still tested with a shortened source; it inserts one 131-byte REM line, number 2901, and moves the DEF line to offset 1536.
- Block 6 is required to run the program to completion: it holds the whole of `PROCconstellations`, which line 150 calls before `END`. If the procedure were missing, BBC BASIC would stop with `No such PROC`.
- The formal integration test for the decoder output (task 8) and the property test for determinism (task 6.9) were not written here.
