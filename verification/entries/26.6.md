- Colour mismatch: the screenshot pixels of the coloured cells are not the CSS hex values, while neutral colours are exact. `web/dist/assets` contains `2e7d32`, `c62828` and `1565c0`, and the PNGs carry no colour profile chunk (`IHDR`, `sBIT`, two `tEXt`, `IEND`). A browser or display colour conversion is the likely cause, but it was not determined; treating the CSS values as Display P3 does not reproduce the observed blue (`#0067c7` against `#344ac4`). The contrast of white text on the rendered colours, computed with the WCAG formula, is 4.55:1 (green), 5.64:1 (red) and 7.19:1 (blue), so white text on all three is still at least 4.5:1 as rendered. The 4.5:1 check in `web/src/status.test.ts` applies to the CSS values (5.13, 5.62, 5.75).
