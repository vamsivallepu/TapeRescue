### Server contract points for task 19.3
`server/` does not exist yet, so these envelope details come from the design and the client defines them. Task 19.3 should either match them or update `api.ts`:
- `CaptureSummary.status` is `"ok" | "error"`. The design only shows `"ok"`.
- `capture_id` may be `null` for a rejected capture.
- A session-level error such as `no_anchor` uses `capture_index: null`.
- `report` and `export` are `null` when no capture decoded.
- 409 bodies carry `blockers`. 400 and 404 errors carry a string `detail` or `message`.
