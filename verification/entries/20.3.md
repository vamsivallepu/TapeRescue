### Changes (all new, under `web/src/`)

- `BlockInspector.tsx`: `BlockInspector({report, blockNo, displayNames?})`. `blockNo` is the selected block, or `null` when nothing is selected. `displayNames` maps capture ID to upload name; a capture without a name shows the first 8 hex digits of its ID (`shortId` from `CaptureStrip.tsx`). The component renders a `<section>` labelled by an `<h2>` (`Block N`) containing:
  - A `<dl>` with the status (text plus the status colour from `status.ts`). It also holds the report's `label` as "Decision", the report's `reason_message` as "Reason" when one is set, and the block's recorded data CRC as `0x8A59`-style hex. For Intact and Reconstructed blocks it adds "Supplied by" with the capture names from `supporting_capture_ids`. When reconstruction was attempted it adds candidate, evaluated and CRC match counts. For a conflict it adds the conflict kind and capture names. All decision text comes from the report (`STATUS_LABELS` and `REASON_MESSAGES` in `taperescue/engine/report.py`). The component adds no explanatory strings of its own.
  - A reads table (`<caption>Reads of block N by capture</caption>`, `<th scope="col">` headers, one `<th scope="row">` per read). Columns: capture, sample offset, header CRC outcome, data CRC outcome, recorded data CRC in hex, expected and actual length, and payload state. A capture listed in `report.inputs` with no read of the block gets a row saying "No read of this block".
  - A differing-offsets table, shown only when the report has choices for the block. Columns: offset, then each capture's observed value as `0x61 (97)`. Several values from one capture are listed comma-separated, and a capture with no value shows "Not observed". The Chosen and Supplied by columns are rendered only for `Reconstructed · CRC match`. Other statuses never show chosen bytes, even if the data carried them.
  - `formatByte` and `formatCrc` are exported for reuse.
- `inspector.css`: local styles only (no `url(`, `@import` or remote reference). Wide tables scroll inside a wrapper `div`, because `display: block` on the table itself can drop its table role for screen readers.
- `BlockInspector.test.tsx`: uses the real reports in `src/test-fixtures/`.
