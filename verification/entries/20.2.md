### Changes (all new, under `web/src/`)
- `status.ts`
  - `BLOCK_STATUS_STYLES`: label, background colour and text colour per `BlockStatus`, from the design table: Intact `#2e7d32`, CRC failed `#c62828`, Reconstructed (for `Reconstructed · CRC match`) `#1565c0`, Unresolved `#ef6c00`, Conflict `#6a1b9a`, Missing `#616161`. Text is white except on amber, which uses `#1a1a1a` because white on `#ef6c00` is about 3.1:1, below the 4.5:1 WCAG AA threshold for small text.
  - `CaptureReadStatus` and `CAPTURE_READ_STYLES` for per-capture cells, derived from the report's per-block `reads` for that capture: `Intact` (header CRC valid, and the payload is empty or complete with a valid data CRC), `CRC failed` (complete, data CRC invalid), `CRC unreadable`, `Truncated`, `Header failed` (header CRC not valid), and `Missing` (no read placed at the block). Colours reuse the design tokens: green for a good read, red for a read failing a CRC check, amber for missing evidence (truncated or unreadable CRC), grey for no read.
  - `readStatus(read)` and `captureReadStatus(block, captureId)`. When a capture read a block more than once, the best read is shown (Intact > CRC failed > CRC unreadable > Truncated > Header failed) and the read count goes into the accessible name.
- `CaptureStrip.tsx`
  - `BlockStrip`, the shared row: a `<section>` labelled by an `<h2>` (so it is a named `region`) containing an `<ol role="list">` with one `<button type="button">` per block. Each button shows the block number and the text label, sets `aria-pressed` for the selected block, has an `aria-label` such as `Block 6: CRC failed` that contains the visible text, and a `title` tooltip. Native buttons give keyboard operation (Tab, Enter, Space). Colours are applied through React's `style` prop, which React sets through the CSSOM, so the API's CSP `default-src 'self'` does not block them.
  - `CaptureStrip({report, captureId, title?, selectedBlock, onSelect})`: one cell per `report.blocks` entry. The heading is the upload's display name with the first 8 hex digits of the capture ID, or `Capture <id8>` when no name is given.
- `MergedStrip.tsx`: `MergedStrip({report, title = "Merged result", selectedBlock, onSelect})`. The cell shows the merged status label. The accessible name carries the full status (`Block 6: Reconstructed · CRC match`), and the tooltip shows `reason_message`, else `label`.
- `strips.css`: local styles only (no `url(`, `@import` or remote reference). The selected cell gets a 3 px dark outline, focused cells get a `:focus-visible` outline, and cells wrap on narrow screens.
- `status.test.ts`, `strips.test.tsx` (co-located, like `api.test.ts`), using the real reports in `src/test-fixtures/`.
