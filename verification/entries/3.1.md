## Task 3.1: Shared data models (`taperescue/models.py`)

Requirements: 2.2, 2.4, 2.6, 2.7

### Changes

- `taperescue/models.py`: literals `CrcOutcome`, `BlockStatus`, `UnresolvedReason` (plus helper `PayloadState`), and frozen dataclasses `HeaderFields`, `CrcReading`, `BlockObservation`, `CaptureObservations`, `RecoverOptions`, `BlockResult`, `RecoveryResult`, with field names and types as in the design's Data Models section.
  - `HeaderFields.identity_key()` returns `(filename, load_addr, exec_addr, block_no, block_len, flags)`. `next_addr` is excluded.
  - `CrcReading` rejects an unknown outcome, a value with `unreadable`, a missing value otherwise, and values outside `0..0xFFFF` (Requirement 2.7).
  - `BlockObservation` rejects `len(payload) != actual_len` and `actual_len > expected_len`, so a padded or overlong payload cannot be built (Requirements 2.4, 2.5).
  - `payload_state` is `empty` when `expected_len == 0` and the header CRC is valid, `truncated` when `actual_len < expected_len`, otherwise `complete`. A zero-byte read of a 256-byte block is `truncated`, not `empty` (Requirement 2.6).
  - `is_intact` requires a valid header CRC and either an empty payload or a complete payload with a valid data CRC.
  - `CaptureObservations` rejects observations whose `capture_id` differs from the capture's.
  - `RecoverOptions(reconstruct=True, candidate_cap=64)` lives in `models.py` as the task lists it. The engine can re-export it.
  - `BlockResult.reconstruction` is typed as `ReconstructionOutcome | None` through a `TYPE_CHECKING`-only import from `taperescue.engine.reconstruct`, so there is no runtime import of the engine. `BlockResult.is_recovered` is a small helper (status `Intact` or `Reconstructed · CRC match` with a payload).
  - `RecoveryResult.program_payload()` returns the concatenated payloads of blocks `0..final_block`, or `None` when `final_block` is `None`, a block is absent or duplicated, or any block is not recovered.
- `tests/test_models.py`: 13 unit tests covering the identity key, CRC reading invariants, complete, truncated, and empty payload states, intact checks with invalid headers, rejection of padding, capture ID consistency, immutability, option defaults, and `program_payload()`.
