## Task 12.5: Write property test for byte provenance
Property 15: Reconstructed bytes trace to observations. Validates Requirements 9.5, 10.4, 13.2.
### Changes
- `tests/properties/test_prop_provenance.py` (new). Strategies are local to the file; no shared `strategies.py` was created.
  - Generator `sessions()`: two captures with distinct random 64-hex IDs, passed to `recover` in a random order. Block 0 is an intact anchor in both, block 2 is the intact final block (flag `0x80`), block 1 is the target. The target holds a random 1–48 byte original payload; each capture's read carries 1–3 single-bit XOR flips and the original recorded data CRC (outcome `invalid` unless the flip happens to keep the CRC). About 3 in 4 sessions split the offset range so A and B damage disjoint offsets; the rest draw both from the whole range, so offsets can overlap. Capture A may add a second valid-header re-read of block 1 with its own damage, and may add an invalid-header read placed at block 1 with random bytes that must never be used.
  - `test_reconstructed_bytes_trace_to_observations` (300 examples, `derandomize=True`, `deadline=None`): for every block with status `Reconstructed · CRC match`, checked against the generated valid-header reads, not the engine's bookkeeping:
    - every payload byte is a value observed at that offset in at least one valid-header read;
    - offsets where all valid-header reads agree keep the agreed value;
    - the `OffsetChoice` offsets are exactly the differing offsets; each `observed` equals the sorted `(capture_id, value)` pairs from valid-header reads; `chosen` is among them and equals the payload byte; `supporting_capture_ids` equals exactly the sorted captures that observed `chosen` there;
    - `crc16_xmodem(payload)` equals the recorded data CRC; `match_count == 1`; block `supporting_capture_ids` are a subset of the captures with valid-header reads.
  - `test_generator_reaches_reconstruction`: guards against a vacuous pass by asserting that at least 20 of 200 fixed generated sessions reconstruct block 1.
  - `test_example_unique_repair_provenance`: fixed case (A flips offset 1, B flips offset 3) reconstructs the original, with offset 1 supported by B and offset 3 by A.
- No engine code changed. No counterexample was found.
