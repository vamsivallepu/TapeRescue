## Task 6.6: Damage injector
Requirements: 5.1, 5.3, 5.4
### Changes
- `taperescue/fixtures/damage.py`:
  - `BitFlip(block_no, offset, bit)` (frozen): `offset` is the payload offset, `bit` is one bit index 0-7 (0 is least significant). `__post_init__` rejects non-integer fields (including `bool`), a block number outside 16 bits, a negative offset, and a bit index outside 0-7, so a multi-bit mask such as `0x30` cannot be passed as a bit. `mask` returns `1 << bit`.
  - `apply_damage(frames, block_no, flips) -> list[ByteFrame]`: returns a new frame list for block `block_no` with each flip XORed into the payload frame at that payload offset. It rejects a flip that names another block, a flip whose offset is not an existing payload frame (offsets past the payload, which is where the data CRC frames sit, and any flip on an empty block), and a repeated offset, so each damaged byte differs from the original by exactly one bit. The sync, header, header CRC, and data CRC frames are copied unchanged and no CRC is recomputed. Frame count, order, roles, and offsets are unchanged, so the modulator produces the same start bits, stop bits, and timing. The input list is not modified.
  - Imports only `taperescue.fixtures.block_builder`, not `taperescue.decoder_adapter`.
- `tests/test_damage.py`: 23 unit tests on block 6 of an 1800-byte program using the planned A flips (offset 17 bit 2, offset 143 bit 5). They check that only the two payload frames change, each by one bit; that roles, offsets, and order are unchanged; that the sync, header, header CRC, and data CRC frames are unchanged, the data CRC frames still hold the original CRC, and the damaged payload fails it; that the input is not mutated; a flip on the short last block; and rejection of offsets 256, 257, and 300, flips on an empty block, repeated offsets, a flip for another block, bit indexes -1, 8, `0x30`, and 255, non-integer fields, and a negative offset. One test checks the import graph.
